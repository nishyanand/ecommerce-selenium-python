\## Description



This assignment demonstrates identifying and locating web elements using Selenium with Python.

1\. Assignment 1: Identify and locate web elements using ID, Name, Tag Name, Link Text, and Class Name.

3\. Assignment 3: Use CSS selectors with wildcard operators for dynamic attributes.

4\. Assignment 4: Identify and interact with child/nested web elements using CSS child selectors.
